# Piercer Crypto Studio — Cotações, DCA, P&L & Imposto

Cotações ao vivo (CoinGecko), conversor Crypto/USD/BRL, calculadora de preço médio (DCA), P&L e DARF 35k

## Funcionalidades

- **Seções principais**: Conversor & Calculadora de P&L (Trade), Calculadora DCA (Preço Médio) & Imposto BR
- **Ações disponíveis**: Atualizar Cotações, + Compra
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8135`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8135`.
